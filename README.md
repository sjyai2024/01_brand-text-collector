# 01 Brand Text Collector v2.6

## 다중 브랜드 추가 오류 수정
- URL 입력을 Streamlit form 밖으로 이동하여 변경된 URL이 즉시 반영되도록 수정
- 브랜드 추가 후 URL 입력창 자동 초기화
- `입력 URL 지우기` 버튼 추가
- 자동인식 브랜드명이 기존 브랜드와 같아도 다른 URL이면 덮어쓰지 않고 별도 항목으로 보존
- 동일 브랜드/동일 URL의 중복 추가 경고
- 현재 선택 브랜드를 목록에서 제거하는 버튼 추가
- 기존 페이지 승인 → Content Unit 승인 → 통합 CSV 흐름 유지
